# IF-002 Deterministic WASM Conformance Vectors

`AGCP-WASM-PEC-Test-Vectors.json` provides implementation-independent vectors for the controlled profile companion `IF-002-WASM-RUST-STUDENT-SERVICE-2.0.0`.

Coverage includes canonical input/output bytes and digests, ABI export and result-packing rules, prohibited imports, module substitution, fuel, memory, timeout, trap, output-limit, unsupported ABI, and attempts to assert authority that a Policy Evaluation Module does not possess.

These vectors supplement the Formal Test Cases and do not replace the authoritative TC procedures.
