# TC-021 — Commit While Rejected

**Requirement**
CR-021 — Rejected actions SHALL NOT become operationally real.

**Conformance Level**
L4 — Execution Authorization Control

### Preconditions

* Proposal state = REJECTED.

### Request / Scenario

Attempt commit of previously rejected proposal.

### Simulated Execution Trace

Step 1 — Commit request received.

Step 2 — Governance state retrieved.

Step 3 — REJECTED state identified.

Step 4 — Commit denied.

### Ledger Delta

```text

Reason=ProposalRejected
```

### Derived State After Request

```text
REJECTED
```

### Expected Result

```http
403 Forbidden
```

### What This Test Proves

Rejected proposals cannot transition into execution.
