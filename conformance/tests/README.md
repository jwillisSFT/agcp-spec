# AGCP Conformance Test Cases

This directory contains the individual AGCP Conformance Test Cases.

Each Runtime Governance Requirement (CR) is verified by exactly one Conformance Test Case (TC).

Each Test Case verifies every Normative Statement (NS) mapped to the corresponding Runtime Governance Requirement in the Requirements Traceability Matrix (RTM).

To facilitate repository management and review, Test Cases are developed and maintained in batch files.

Current batches include:

- TC001-TC010.md
- TC011-TC020.md
- TC021-TC030.md
- TC031-TC040.md
- TC041-TC050.md
- TC051-TC060.md
- TC061-TC070.md
- TC071-TC080.md
- TC081-TC090.md
- TC091-TC100.md
- TC101-TC110.md
- TC111-TC121.md

Each batch contains the complete Conformance Test Cases for the indicated range and collectively constitutes the AGCP Conformance Test Suite.
