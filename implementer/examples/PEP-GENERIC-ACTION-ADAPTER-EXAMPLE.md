# Generic PEP Profile Example

This informational example demonstrates exact mappings from two generic governed actions to a protected enforcement adapter.

The GRF applies this profile only after current commit eligibility is established. Unsupported operations have no approximate fallback. The PEP uses a target-writer credential distinct from proposal-side authority and returns evidence that can be bound to the commitment and later asynchronous target outcome.

See `PEP-GENERIC-ACTION-ADAPTER-EXAMPLE.yaml` for the machine-readable example.
