# Contributing to AGCP

The AI Governance Control Plane (AGCP) is published for open technical
review and implementation evaluation.

Sustainable Future Tech welcomes technical feedback, specification
questions, implementation experience, interoperability proposals,
conformance observations, and identified defects through GitHub Issues.

## Governance and Change Authority

AGCP is independently governed and maintained by Sustainable Future Tech
(SFT).

Public participation in AGCP review does not confer governance,
maintainer, approval, or decision-making authority over the project.

Submission, discussion, or acknowledgement of an issue does not imply
acceptance of a proposed change.

The authoritative AGCP specification, architecture, schemas, registries,
interfaces, traceability artifacts, and conformance materials may be
changed only through the AGCP controlled change-management and release
process.

Where public feedback identifies a potential normative or structural
change, the AGCP maintainers determine whether the matter enters the
formal change-control process. Accepted changes become authoritative only
when incorporated into a controlled AGCP release.

## Public Technical Review

GitHub Issues are the public mechanism for submitting:

- normative defects;
- structural gaps;
- specification ambiguities;
- determinism concerns;
- conformance questions;
- interoperability observations;
- multitenant governance isolation concerns;
- security-architecture concerns; and
- proposed clarifications or improvements.

Reviewers should identify the relevant repository artifact, specification
section, assertion or requirement identifier where applicable, and a
proposed resolution when possible.

## Repository Changes

External review and feedback are conducted through GitHub Issues.

Pull requests affecting AGCP specification or controlled repository
content are restricted to authorized collaborators and maintainers.

Normative specification changes are implemented through the AGCP
controlled change process and become effective only through an
authoritative versioned release.

## Security Vulnerabilities

Do not disclose exploitable vulnerabilities, sensitive implementation
details, credentials, or other security-sensitive information in a
public GitHub Issue.

Use the repository's private vulnerability-reporting mechanism for
security vulnerabilities.

## Intellectual Independence

Participation in public AGCP review does not transfer ownership,
governance, project assets, trademarks, repositories, or architectural
authority to reviewers, participating organizations, standards bodies,
alliances, or other third parties.

Specific materials separately contributed by SFT to another project or
organization are governed by the terms applicable to those specific
contributions.
