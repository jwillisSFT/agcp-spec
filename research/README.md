# Research

**Status:** Informational  
**Repository Versioning:** Repository Release Governed

## Purpose

This directory contains research papers, technical reports, architectural analyses, and supporting reference material that informed the development of the Autonomous Governance Control Plane (AGCP).

These publications document the architectural evolution, formal foundations, and design rationale behind AGCP. They are provided to assist readers in understanding the concepts that influenced the normative specifications.

The contents of this directory are **informative** and are **not part of the AGCP normative specification**.

---

# Relationship to the Specifications

The AGCP normative specifications are contained in:

```text
/spec/
```

The research publications in this directory explain architectural concepts, present formal analyses, discuss design rationale, provide historical context, and explore implementation considerations.

They **do not define normative implementation requirements**.

Where a research publication differs from a published AGCP specification, the specification takes precedence.

# Notes

The repository is organized into complementary layers:

- **Specifications** define normative behavior.
- **Reference** documents explain the specifications.
- **Lifecycle** documents describe governance progression.
- **Conformance** artifacts verify implementation behavior.
- **Research** publications provide the architectural and theoretical foundation that informed the design of AGCP.
