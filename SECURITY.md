# AGCP Security Policy

## Reporting a Vulnerability

Please do not report exploitable vulnerabilities or sensitive security
information through public GitHub Issues.

Use GitHub Private Vulnerability Reporting for this repository whenever
possible.

If private vulnerability reporting is unavailable, contact:

research@agcp.ai

Please include sufficient information to reproduce and evaluate the
reported condition, including affected AGCP version, relevant artifact or
interface, expected behavior, observed behavior, and potential security
impact.

## Specification Security Concerns

Public architectural or specification-level security questions that do
not disclose an exploitable vulnerability may be submitted through the
AGCP Specification Review issue form.

## Supported Baseline

Security review should normally be performed against the current
published AGCP controlled baseline unless the report specifically concerns
a prior release.

## Disclosure

Please allow the AGCP maintainers reasonable opportunity to investigate
and address a reported vulnerability before public disclosure.
